What we learned while planning, building, and checking this educational site.

Project reflection and AI usage report

First Aid, First began with a practical question: what would help someone find a calm starting point when an everyday emergency feels confusing? We chose an educational website because the topic has clear value beyond the classroom. The goal was to offer short, understandable introductions to three related areas: the first response sequence, serious external bleeding, and burns. We also wanted the website to encourage formal first aid training, because a brief web page cannot give someone the experience of hands-on practice.

Planning the information architecture was an important lesson. The assignment requires exactly seven pages, so we assigned a distinct job to each one. The home page introduces the service and collects registration interest. Three subtopic pages carry the learning material. The planning page explains design choices, the reflection page records our process, and the overview page presents the project documentation. A shared navigation bar and footer make these separate pages feel like one website. We used the same CSS file throughout, which made changes to colors, spacing, and typography easier to maintain.

The visual design was shaped around the emotional needs of the audience. Deep navy provides a steady background, cream makes long sections easier to read, and coral calls attention to buttons and warnings. Aqua highlights supportive guidance. We paired Lexend headings with Source Sans 3 body text, loaded through Google Fonts with Arial fallbacks, to give the site more character while keeping the guides readable. Large headings help users understand each page quickly, while cards and numbered steps break information into manageable parts. We checked how the layout changes on a smaller screen and arranged the cards in one column when space is limited.

Our main interactive feature is the registration form. JavaScript checks the first and last names, mobile number, and email address before showing a message. Building it reinforced the connection between HTML form fields and JavaScript functions. The form deliberately gives feedback in the browser without claiming that details were saved or sent. That choice also avoids collecting personal information in this classroom version. If the site became a real public service, it would need a secure server, a privacy notice, and a clear process for handling user data.

We used the Codex assistant to help organize the page plan, draft the visual direction, write initial HTML, CSS, and JavaScript, and review the wording. The prompts and changes are documented in the overview table. AI output was treated as a draft requiring human review. In particular, first aid advice can have serious consequences if it is wrong or incomplete. We kept instructions short and checked the practical statements against the American Red Cross and NHS pages linked in the site footer. The AI-generated illustrations are decorative and do not teach medical procedures.

Team collaboration should involve dividing research, content checking, design review, and testing among group members, then reviewing the final pages together. The biggest lesson is that an attractive website also needs accurate content, accessible wording, honest form behavior, and transparent credit for outside sources and AI help. Further improvement would include feedback from first aid educators and real users before publishing the site for public use.
