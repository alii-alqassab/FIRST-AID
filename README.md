# First Aid, First

A responsive first aid education website built with HTML, CSS, and JavaScript.

## Run locally

Clone the repository and open `home.html` in a browser. No installation or build step is needed. Keep the `css`, `js`, and `images` folders alongside the HTML pages. Google Fonts requires internet access; fallback fonts work without it.

## Deploy on Vercel

Use the **Other** framework preset with the repository root as the project directory. No build command is needed. The root `vercel.json` routes `/` to `home.html`, preserving the seven filenames required by the assignment.

## Pages

- `home.html`: topic directory, situation selector, first aid kit guide, learning questions, and registration form.
- `subtopic1.html`: emergency response, adult CPR and AEDs, recovery position, and choking.
- `subtopic2.html`: severe bleeding, small wounds, shock, and nosebleeds.
- `subtopic3.html`: burns, urgent warning signs, chemical and electrical burns, and aftercare.
- `planning-design.html`: design choices, wireframes, and layout previews.
- `reflection-ai-report.html`: project reflection and AI report.
- `overview.html`: requirements, site map, user journey, style guide, and AI documentation.

## Features

- Responsive layouts with keyboard focus indicators and labeled controls.
- Situation selector and practice questions with feedback.
- Registration validation: names of at least three characters, an eight-digit mobile number, and email format checks.
- Bahrain emergency contact link and source references beside the guidance.

The registration form is a browser demonstration and does not save or send personal information.

## Credits and scope

First aid guidance links to the American Red Cross, NHS, and St John Ambulance. The illustrations were generated with AI assistance, which is documented on the project overview page. Typography uses Lexend and Source Sans 3 from Google Fonts.

This educational website supports awareness and does not replace practical first aid training, emergency dispatcher instructions, or professional care.
